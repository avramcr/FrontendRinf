# FusionCart Frontend
## Repository

GitHub: [https://github.com/avramcr/FrontendRinf]

## Instalare

```bash
git clone https://github.com/avramcr/FrontendRinf
cd FrontendRinf
npm install
```

## Rulare aplicație

```bash
npm run dev
```

## Tehnologii utilizate

* Next.js
* React
* TypeScript
* PostgreSQL
